# HOPPO Frontend

Frontend de **HOPPO**, una plataforma de comercio electrónico full-stack.  
La aplicación está desarrollada con **React** y proporciona la interfaz de usuario para explorar productos, gestionar el carrito de compras y realizar pedidos, interactuando con la API del backend.

## Features

- Navegación y exploración de productos
- Gestión del carrito de compras
- Registro e inicio de sesión de usuarios
- Visualización de pedidos
- Integración con la API REST del backend

## Tech Stack

- React
- JavaScript
- HTML
- CSS
- REST API Integration

## Instalación

Clonar el repositorio:
- git clone https://github.com/MarcoTrujillo10/hoppo-ecommerce-frontend.git

Instalar dependencias:
- npm install

## Ejecutar la aplicación

Iniciar el servidor de desarrollo:
- npm start
